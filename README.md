# Weather Dashboard

A simple, elegant weather dashboard built with HTML, CSS, and JavaScript. It lets users search for a city or use their browser location to view live current weather conditions using the OpenWeatherMap API.

## Overview

This project is a front-end weather application that displays weather information in a styled dashboard card. Users can enter a city name, submit the search form, or click the location button to fetch weather data based on the device’s current geolocation.

## Features

- City weather search
- Geolocation-based weather lookup
- Current temperature, humidity, wind speed, and weather description
- Temperature unit toggle between Celsius and Fahrenheit
- Sunrise and sunset display
- Weather emoji and dynamic background styling based on condition codes
- Clear button to hide the active weather dashboard
- Fully static HTML, CSS, and JavaScript implementation

## Project Files

- `index.html` — page layout and UI structure
- `weather.css` — visual styling for the dashboard
- `weather.js` — API calls, geolocation handling, DOM rendering, and UI interactions





## Notes

This project depends on browser APIs such as `fetch()` and the geolocation API. Ensure your browser allows location access and has a network connection when testing the app.
