# 🌦️ Weather App

A simple and responsive weather application built with HTML, CSS, and JavaScript that allows users to check current weather conditions by searching for a city or using their current location.

## ✨ Features

* **Search by City:** Get real-time weather details for any city worldwide.
* **Geolocation Weather:** Automatically fetch weather data based on your current device location.
* **Dynamic Backgrounds & Emojis:** UI changes dynamically based on weather conditions (sunny, rainy, snowy, thunderstorms, etc.).
* **Temperature Unit Toggle:** Easily switch between Celsius (°C) and Fahrenheit (°F).
* **Detailed Information:** Displays temperature, "feels like" temperature, humidity, wind speed, weather description, sunrise, and sunset times.
* **Secure API Handling:** Uses browser `localStorage` to securely manage the OpenWeatherMap API key without exposing it publicly.
